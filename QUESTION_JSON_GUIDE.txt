QUESTION JSON -> QUIZ GUIDE

This project already uses questions.json as the question source for the quiz.
On first run, questions.json is seeded into MongoDB automatically.

If you add NEW questions to questions.json later:
1. Login to Admin Panel.
2. Open Question Bank.
3. Click "📥 Import questions.json".
4. New questions will be added to the database.
5. Existing/repeated questions are skipped automatically.
6. Quiz will then use the updated Question Bank.

JSON format:
[
  {
    "q": "Your question?",
    "options": ["Option 1", "Option 2", "Option 3", "Option 4"],
    "correct": 1
  }
]

correct is the option index:
0 = Option 1
1 = Option 2
2 = Option 3
3 = Option 4
