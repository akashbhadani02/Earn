BOOK FILE

Replace this file:
public/books/book.pdf

with your real book PDF, keeping the same filename: book.pdf

The Earn page will download:
1) Aducate_Book_Payment_<receipt-id>.pdf (payment success certificate/receipt)
2) book.pdf (your actual book)

IMPORTANT:
The current UPI flow is temporary. The student confirmation is recorded in the database, but the browser cannot prove a UPI transaction happened. Admin must check the GPay/bank statement and click Verify in Admin > Book Payments.
